# editPDFbyAI 1.0.0

[English guide](https://github.com/smartgalilei/editPDFbyAI/blob/v1.0.0/README.md) · [中文使用说明](https://github.com/smartgalilei/editPDFbyAI/blob/v1.0.0/README.zh-CN.md) · [日本語ガイド](https://github.com/smartgalilei/editPDFbyAI/blob/v1.0.0/README.ja.md)

Edit PDFs with natural language using your own DeepSeek API key. PDF processing runs locally; the interface opens in your browser.

- English, AI-only interface with preview, apply, undo/redo and export.
- Missing-digit approximation enabled automatically when suitable font references exist. Generated glyphs remain identified in the preview.
- Text replacement, alignment, text/background colors and page organization through AI instructions.
- Separate macOS Apple Silicon, macOS Intel and Windows x64 downloads with Python included.
- English, Chinese and Japanese guides included in every package.

**Run:** Extract the entire archive, then open `editPDFbyAI` on Mac or `editPDFbyAI.exe` on Windows. Keep the terminal open while editing and export before quitting. The initial Mac packages target macOS 15+; Windows packages target Windows 10/11 x64. These binaries are unsigned and not Apple-notarized.

**Privacy:** Only selected pages' extracted text, coordinates and your instructions are sent to DeepSeek. PDF files are processed locally. API usage is billed to your own account. No API key is included.

**Validation:** Automated source tests and packaged startup/render/export checks run on all three build platforms. AI integration tests use mocked responses; no real DeepSeek key was used for release validation.

**License:** AGPL-3.0. Dependency licenses are included. The source archives for this tag are the corresponding source for these binaries. `.sha256` files provide checksums for the downloads.
