# editPDFbyAI

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

自然言語で PDF を編集するツールです。変更内容を入力し、実際の PDF プレビューを確認してから適用・書き出しできます。AI には、ご自身の DeepSeek API キーを使用します。

PDF の処理はお使いのパソコン上で行い、操作画面はブラウザーで開きます。クラウドの PDF 処理サーバーは不要です。アプリの画面は英語ですが、編集指示には日本語・英語・中国語を使用できます。指示の理解精度はモデルに依存します。

## ダウンロードと起動

[Releases](https://github.com/smartgalilei/editPDFbyAI/releases) から、お使いの環境に合うファイルをダウンロードしてください。

| 環境 | パッケージ |
| --- | --- |
| Apple Silicon 搭載 Mac（M シリーズ） | macOS-arm64 |
| Intel 搭載 Mac | macOS-x64 |
| Windows x64 | Windows-x64 |

**アーカイブ全体を展開**し、Mac では `editPDFbyAI`、Windows では `editPDFbyAI.exe` を起動してください。Python と PDF エンジンは同梱されているため、別途インストールする必要はありません。ブラウザーが自動的に開きます。使用中はターミナルを開いたままにし、終了するにはウィンドウを閉じるか Ctrl+C を押してください。終了前に変更をエクスポートしてください。

初回の Mac パッケージは macOS 15 以降、Windows パッケージは Windows 10/11 x64 を対象としています。Windows ARM ネイティブ版は提供していません。初版にはコード署名や Apple の公証がないため、開発元の確認に関する警告が表示される場合があります。下記の手順でソースから実行することもできます。インストールのためにシステムのセキュリティ保護を無効にしないでください。

## 使い方

1. **Open PDF** でファイルを開くか、**Try a sample document** で架空のサンプルを試します。
2. **API settings** を開き、ご自身の DeepSeek API キーを入力してモデルを選択します。
3. **Scope** で現在のページ、全ページ、またはページ範囲を選択します。
4. 変更内容を入力し、**Preview changes** をクリックします。
5. 変更前後を比較し、**Apply changes** で適用した後、**Export PDF** で書き出します。

指示の例：

- 「納品日を 2026 年 11 月 1 日に変更し、それ以外は変えないでください。」
- 「1 ページ目のタイトルをページの水平方向の中央に配置してください。」
- 「タイトルの文字を濃い青、タイトルの矩形背景を薄い黄色にしてください。」
- 「2 ページ目を時計回りに 90 度回転してください。」

直近 10 回の適用済み変更を取り消し・やり直しできます。元のファイルは上書きされません。画面は AI 編集専用で、手動編集パネルはありません。

## 編集動作と制限

文字の置換では PDF 内の既存フォントと描画設定を再利用します。元の文字領域、ページ全体、または指定した矩形を基準に、左・中央・右・上・上下中央・下への配置を指示できます。文字色と単色の矩形背景色も変更できます。

**不足している数字の字形は標準で近似補完します。** 対応する埋め込み Bold フォントと、同じファミリーの Regular フォントに完全な数字セットがあることが条件です。生成字形は近似であり、元のフォントデザインと同一ではありません。既存の字形は保持されます。近似字形を使用した場合は、プレビューと文書の通知に表示されます。参照字形が足りない場合や未対応のフォントでは、変更を拒否します。

固定レイアウト向けの編集ツールであり、すべての PDF を自由に編集できるわけではありません。未対応の文字コード、重複オブジェクト、複数スタイルをまたぐ置換、領域不足、対象外の意図しない見た目の変化を検出すると、変更を拒否します。OCR によるスキャン文字の編集や、画像・グラデーション・複雑な透明背景の色変更には対応していません。編集により電子署名が無効になる場合があります。文字削除は、隠れたデータの完全な除去を保証しません。

上限は 40 MB、300 ページ、1 回のプランにつき 60 操作です。AI に送るテキストは約 100,000 文字までです。文書と履歴はサービスのメモリー内だけに保持され、終了すると失われます。複数のタブは同じローカルセッションを共有します。

## プライバシーと API 料金

PDF の読み込み、描画、編集、書き出しはローカルで行います。AI リクエストでは、**選択ページから抽出した全文**、座標、編集指示を `https://api.deepseek.com/chat/completions` に送信します。PDF ファイル本体やページ画像は送信しません。DeepSeek による処理と課金には、ご自身のアカウントの条件が適用されます。

API キーはローカルサービスのメモリー内だけに保存し、設定ファイルやブラウザーのストレージには書き込みません。環境変数 `DEEPSEEK_API_KEY` でも指定できます。テレメトリーはありません。サービスは `127.0.0.1` のみに接続を受け付け、ランダムなセッショントークンと Host・Origin の検証を使用します。LAN やインターネットに公開したり、セッション URL を共有したりしないでください。

## ソースから実行

Python 3.11 をインストールしてソースをダウンロードし、`start-macos.command` または `start-windows.bat` をダブルクリックします。初回は依存パッケージのインストールにネット接続が必要です。

Mac のターミナル：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Windows PowerShell：

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

## 開発・テスト

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
python -m pip install pyinstaller==6.22.3
python scripts/build_desktop.py
python scripts/smoke_desktop.py
```

各対象 OS 上で個別にビルドしてください。PyInstaller はクロスコンパイラーではありません。GitHub Actions で 3 種類のパッケージをビルドし、実行ファイルの起動、画面リソース、PDF の描画と書き出しを確認します。テストには架空の文書と模擬 AI 応答を使用します。実際の DeepSeek 呼び出しの動作確認には、有効な API キーと残高が必要です。
